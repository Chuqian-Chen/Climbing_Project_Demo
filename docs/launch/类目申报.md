## 服务描述（后台"服务内容声明"可直接粘贴）

```
「岩友Beta」是一款面向攀岩爱好者的个人运动记录工具。

核心功能：
1. 攀爬打卡：用户记录自己在攀岩馆完成的线路（难度、次数、感受），
   生成个人足迹统计（热力图、难度金字塔、连续天数）。
2. 攀爬笔记：用户可为自己攀爬过的线路撰写图文笔记（俗称 Beta，
   即线路解法心得），笔记默认属于个人记录，可选择公开供其他
   攀岩爱好者参考。
3. 岩馆信息：收录北京、上海攀岩馆的位置与线路信息，基于用户
   授权的地理位置推荐附近场馆（使用 getLocation 接口）。

内容安全：用户上传的文字与图片均通过微信内容安全接口
（security.msgSecCheck / imgSecCheck）先行检测，检测不通过的内容
无法发布。应用内提供内容规范提示与安全声明。
```

## UGC 场景声明（后台若单独要求）

```
本小程序 UGC 场景为：用户对自己完成的攀岩线路撰写的图文记录
（攀爬笔记）及对他人公开笔记的留言。所有用户上行内容（文字、
图片）在写入前均调用微信官方内容安全能力 security.msgSecCheck、
security.imgSecCheck 进行机器检测，检测为违规的内容直接拦截，
无法发布。运营方保留对已发布内容的删除权。
```
