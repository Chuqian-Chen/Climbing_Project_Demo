# wx.getLocation 接口权限申请材料

入口：mp 后台 → 开发 → 开发管理 → 接口设置 → wx.getLocation → 申请开通

## 申请理由（粘贴）

```
本小程序为攀岩爱好者的运动记录工具，收录了北京、上海共 130 家
攀岩馆的位置信息。需要获取用户地理位置用于：
1. 「岩馆」页按用户与场馆的实际距离排序，帮助用户找到最近的
   攀岩馆（核心使用场景：攀岩爱好者到陌生城区找馆）；
2. 首页「附近岩馆」模块展示 3 家距离最近的场馆及距离；
3. 首页天气提示（攀岩前查看天气决定是否出行）。
位置信息仅在前台使用时获取，仅用于本地距离计算与天气查询，
不存储、不用于任何营销用途。
```
