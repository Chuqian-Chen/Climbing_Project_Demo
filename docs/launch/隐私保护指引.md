# 隐私保护指引填写（mp 后台：设置 → 服务内容声明 → 用户隐私保护指引）

按后台表单逐项勾选/粘贴。只勾实际用到的，多勾会被驳回。

## 需要勾选的信息类型

| 信息类型 | 用途（粘贴） | 对应功能 |
|---|---|---|
| 位置信息（精确位置） | 用于计算用户与各攀岩馆的距离，推荐附近岩馆，并展示当地天气提示 | wx.getLocation |
| 选中的照片或视频信息 | 用于用户发布攀爬笔记、上传墙面照片与打卡海报 | wx.chooseMedia |
| 昵称、头像 | 用于展示用户的攀爬记录归属 | 头像昵称填写能力 |
| 发布内容 | 用户撰写的攀爬笔记、留言与打卡备注，经内容安全检测后存储于微信云开发 | UGC |

## 其他字段

- **信息处理方式**：仅存储于微信云开发（腾讯云），不对第三方提供。
- **信息保存期限**：用户可随时删除自己发布的内容；注销后数据删除。
- **开发者联系方式**：填你的邮箱 chloe.c.chuqian@gmail.com（或微信号）。

## 代码侧已就位（无需再改）

- `app.json` 已含 `requiredPrivateInfos: ["getLocation"]` 与
  `permission.scope.userLocation.desc`。
- 基础库自带隐私弹窗：指引审核通过后，首次调用 getLocation 时
  微信会自动弹官方隐私授权框，代码无需额外处理。

## 提交顺序（重要）

1. 先提交本隐私指引 → 等审核通过（通常 1-2 天）
2. 再提交 getLocation 接口权限申请（见《getLocation审核材料.md》）
3. 最后整包提审小程序

顺序反了 getLocation 申请会因"未配置隐私指引"直接驳回。
